## Executive summary

The OSE platform's constitution (25-invariant architectural-invariants.yaml), its distributed rubric (perStoryTestPyramid + invariant status enum + 10-level brain ladder + CCR), and its documentation are broadly coherent in intent but carry material drift in three recurring patterns: (1) the constitution declaring behavior LIVE that the code has intentionally retired (Invariant #2 surface-filtering/tier-sort superseded by the #25 uniform-placement covenant, yet #2 still reads live and its executable spec still asserts the old contract â€” a false gate that can fail against correct code); (2) enforcement specs and gates that pass vacuously or under-scope the threat they are cited to stop (an inert FORMS_DB anon-table regex; a PII gate that only blocks network identifiers while #1/#4 claim exhaustive raw-PII / anon-identity coverage; a TL-026 born-red test that certifies 'no IP in logs' while a raw CF-Connecting-IP is persisted to admin_audit_log â€” the exact 'red-team theater' the ledger names as TL-033); and (3) pervasive doc-lagging-code counters and status drift (migration counts stated as 40/17/13 vs actual 52/52/13; sponsor is_local documented admin-set while code geo-derives it per live #25; #21 self-contradicting across three YAML surfaces and diverging from standards-index; #23/#24 both absent from the index and understated as 'in construction' despite landed harness/generator). The 'generated never written' auditability doctrine is aspirational: the committed conformance.json was hand-run locally (commit 'local-gap-closure-2', empty run_url), omits the one LIVE invariant in its cluster (#25), and shows four disagreeing threat-entry counts. No single canonical 0-100 scoring rubric exists; the acceptance model is distributed, and the per-story three-layer pyramid is not CI-enforced and is demonstrably lapsing on recent stories (OSE-539 ships vitest only). Confidence is high: every finding is file:line-anchored and survived adversarial verification, though no live/deployed surface or CI run history was fetched.
