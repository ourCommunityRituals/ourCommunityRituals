# Design canvas (copy)

These are the boards from the ourCommunityRituals design canvas on Claude, copied here on 2026-10-08 so Claude Code can read and build from them. The live canvas stays the place to view and comment; this folder is a snapshot.

Each board is a self-contained HTML file (inline styles). Open one in a browser to see it. They reference a `support.js` that only exists in the canvas app, so a missing-script warning in the browser console is expected and harmless. Text in [BRACKETS] is placeholder content.

`canvas.json` holds each board's title and position on the canvas.
