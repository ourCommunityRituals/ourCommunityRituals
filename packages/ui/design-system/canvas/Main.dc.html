One design language for the whole fleet.

Extracted from the hub's packages/ui. It has three tiers, stays readable for color-blind people, and is designed for older adults first. Every spoke pins it through .ocr-hub-ref and repaints it only through a Tier 3 brand.

Tier 1
Primitives

Raw values: --ocr-charcoal-950, --ocr-creme-050, --ocr-signal-500, --ocr-teal-400. Components never reference them directly.

Tier 2
Semantic roles

What components use: --bg, --surface, --accent, --live. Each has a dark and a light value, and every text role clears 4.5:1 on every background.

Tier 3
Brands

A [data-brand] block may re-map only the 13 customizable roles. The 8 status roles and every UEC color are locked.

Principles the code enforces
01
Make every mistake cheap. Prefer undo to a confirm dialog. Validate when someone leaves a field, never while they type.
02
Do the thinking for them. Fill in what the system already knows, and offer the likely answer first.
03
Teal is live, red is destructive. They are never used as opposites, and a status never relies on color alone.
04
48px taps, 16px inputs. Both are measured and enforced in CI on all 11 surfaces.
05
Size QR codes in millimeters. A code must be at least a tenth of its scan distance, sized with a per-panel --display-ppmm.
06
Every dead end offers a next step. Empty and access-denied states always include an action.
